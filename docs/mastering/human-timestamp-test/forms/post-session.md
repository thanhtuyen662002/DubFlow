# Câu hỏi sau phiên

Mã người tham gia: ____  ·  Phiên: ____

Mỗi câu chấm 1–5 (1 = hoàn toàn không đồng ý, 5 = hoàn toàn đồng ý), kèm một dòng tự do nếu muốn.

| # | Câu hỏi | RP | TS |
|---|---|---|---|
| 1 | Tôi tìm được cảnh đúng mà không phải đoán mò. | | |
| 2 | Tôi biết khi nào nên dừng tìm và đánh "không có cảnh phù hợp". | | |
| 3 | Số thao tác cần làm cho mỗi câu là chấp nhận được. | | |
| 4 | Tôi tin vào cảnh mình đã chọn. | | |
| 5 | Tôi sẽ dùng cách này cho một phim dài thật. | | |

Chỉ cho TS:

6. Tôi thường biết cảnh nằm ở khoảng nào của video trước khi bắt đầu tìm. (1–5)
7. Độ chắc chắn tôi ghi (±5 / ±15 / ±30 s) phản ánh đúng mức tôi biết. (1–5)
8. Đánh mốc cho khoảng 60 câu của một phim 35 phút là chấp nhận được. (1–5)

Câu mở:

- Chỗ nào khó nhất ở mỗi cách?
- Có câu nào bạn đã biết cảnh đúng từ trước không? Câu nào?
