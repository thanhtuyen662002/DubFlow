# DubFlow Built-in Vietnamese Voice 1.0

The `vi-builtin-v1` voice pack is an original, app-owned additive synthesis
table distributed with DubFlow under the DubFlow application license. It does
not contain downloaded neural weights, a third-party voice recording, or a
cloud-service credential. The production model manifest pins its byte length,
SHA-256, model ID, version, and this license identifier before the pack is
loaded.

The voice is a deterministic CPU baseline intended to produce a playable
Vietnamese dialogue stem on every supported local-file installation. It is
not marketed as a human voice clone or as a studio-quality neural model.
